Alysum statistics spec

Contract for XP, reputation, comments, reviews, and Word Wars writing XP. Amounts in the tables below are painted from core/statistics/awards.js — that file wins if anything else disagrees.

Written as if chapter comments, reviews, and Word Wars (live writing with other people) are live. Ship those UIs against this document. Do not invent a second XP scheme.

1. Two ladders

  • User level (XP) — site awards when you do things. Cosmetic. Unlocks profile borders through level 30 (308,000 XP). Wear any unlocked border. Do not spend XP on features.
  • Reputation (Rep) — other people give points (public amount + public note). Unlocks a gem at the bottom-center of the border through level 50 (15,190). Also raises daily give count and max per action. Do not spend Rep on borders.

Premium / subscriber borders are a separate pool.

2. Awards (awards.js)

Changing a number affects future grants only. Reversals subtract the amount stored on that xp_events row.

KeyValue
  • null = off (grants 0) until you set a number. writing_sentence starts off.
  • No per-word drip. writing_sentence pays per eligible sentence; the 2k / 10k milestones fire on users.writing_durable_words — sentences that survived their 12-hour provisional window.
  • Rep-level lump XP = rep_level_lump_per_level × repLevel (level 1 → 10, level 50 → 500).

3. XP levels 1–30

Level is the highest n where xp ≥ threshold. Below 100 = level 0. Crossing a level unlocks that border forever (border_unlock_max).

Badge picker: 6×5 grid, column-major (1 top-left, 2–5 down, 6 starts column 2).

LevelXPMetal

+1 rep the first time you reach each XP level (xp_level_grant, ref xp_level:n, unique).

4. Reputation give rules

Button first lives under fiction chapter comments on read. Same RPC later for reviews / lounge (target_type + target_id).

  • Book author cannot receive rep on comments on their own fiction.
  • Authors can give on own-fiction comments: 5/day, or 10/day once own reputation ≥ 5,000 — in addition to the global daily gift count.
  • Default 20 gifts per UTC day. If reputation level > 20, daily gifts = that level.
  • Once per comment/post. At most two gifts to the same user per UTC day.
  • Per-action max from total rep points: 0–200 → 1, >200 → 2, >500 → 3, >1k → 4, >5k → 5, >10k → 6.
  • Giving rep grants 3 XP to the giver regardless of amount.

5. Gems

Color every 5 levels: gray, green, blue, purple, yellow, orange, teal, red, diamond (41–45 facets/corners), royal (46–50 multicolor). Cut/clarity steps 1–5 inside a band: hidden → revealed → cabochon → rough-cut → finished. Displayed gem follows current level; rep_color_unlock is monotonic so color family does not go backward.

6. Rep levels 1–50

Formula: round(6.076 × n × n). n=50 → 15,190.

7. Engagement XP (comments and reviews)

Clock starts at created_at of the comment or review. RPC uses engagement-xp.js. Unlike subtracts the stored amount.

Comments

  • Write: 3 XP, max 24 paying creates per UTC day. Delete reverses a paid create.
  • Incoming like: 3 XP only while the comment is younger than 24 hours, then 0. Already-granted XP stays.
  • No XP from your own like.

Reviews

  • Days 0–7: 15 XP per paying upvote.
  • After 7 days: 5 XP per new paying upvote. Do not rewrite old 15s to 5.
  • Max 100 paying upvotes per review. Un-upvote does not free a slot. Unique voter+review.
  • Delete the review: reverse create (if on) and all upvote XP rows for it.

8. Writing stats vs writing XP

  • Overview today / goal / goal-streak = users.writing_day_totals — only words the writer typed (paste, drop, undo/redo excluded). Minimum goal 1,000. Never grants XP.
  • Writing XP = eligible sentences (2 XP each, provisional 12h), from the solo editor and Word Wars. 2k / 10k milestones on writing_durable_words.

9. Writing XP (solo editor + Word Wars)

Every sentence a writer completes is checked. Solo editing runs it on idle / save / pagehide; Word Wars also seals on leave / finish / kick. grant_sentence_xp re-checks structure server-side; pass → writing_sentences row, provisional 12h.

  • Synced to your real chapter(s) — not a separate buffer. Sentences already wrapped in data-xp-reviewed are skipped; typing inside a reviewed span re-opens it. Publish strips the marks.
  • Word Wars seals once per (user, room) — war_seals. Leaving does not void what you wrote.
  • Layers 0–2 (paste / uniqueness / char-mash / word-list / verb-glue) run client-side. LanguageTool (Layer 2b) is a batched server proxy — not wired yet; until it is, capitalised prose with a real verb (≥4 words) passes locally and the rest is held and re-checked. Layer 3 (AI coherence) deferred.
  • 1-word paste allowed. 2+ word paste/drop voids the sentence (and pasted regions don't count toward the goal).
  • Pass → provisional 12h. Delete / rewrite of that sentence inside 12h → revoke_sentences → reverse_xp_for_ref. Then finalize_writing_xp_sweep (pinged from studio/overview/editor load) promotes it to FINAL, adds the word count to writing_durable_words, grants the 2k / 10k steps.
  • Identity: hash of the normalized text (sentenceReviewKey). Editing a sentence = a new sentence. A given sentence pays once, ever (writing_sentences unique (user, sentence_hash)).

10. Anti-farm

  • Writing XP only from a Word Wars live session (including if you leave early). Paste phrase voids. Solo editor = 0.
  • Own-fiction cannot receive rep on their comments. Unique give target. Two gifts to same user per UTC day.
  • Comment create daily cap. Review max paying upvotes. No slot-free on unlike.
  • Daily login XP is UTC day, once. Login streak is a different local-day system.
