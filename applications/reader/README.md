# Reader

Dedicated reading shell for Alysum.

Icon bar: **Reader** · **Discover** · **What’s New**.

Reader-dedicated URLs (keep Reader toolbar; do not bounce into Writer paths):

| Reader route | Serves |
|---|---|
| `/reader` | Continue / in-progress hub |
| `/reader/discover` | Library catalog hub |
| `/reader/updates` | What’s New |
| `/reader/profile` | Profile |
| `/reader/settings` | Settings |
| `/reader/inbox` | Inbox |
| `/reader/connections` | Following & subscriptions |

Writer keeps `/studio`, `/library`, `/settings`, `/overview`, etc. Switch modes with the mode chip only.
