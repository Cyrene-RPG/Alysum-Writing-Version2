# Waypoint — how to change things

1. **Roadmap columns** — edit `items.js`, commit, push.
2. **A bug someone filed** — open `submissions/bugs/` and the folder named after their title. Read what they said. Change `status` in `report.js` to `open`, `ack`, or `fixed`.
3. **A suggested feature** — open `submissions/suggestions/`. If you want it on the roadmap, copy the title and body into `items.js` (`zone: "planned"`) and set that folder’s `status` to `promoted`.
4. **Images and videos** sit in the same folder as the report. Nothing else to decode.
