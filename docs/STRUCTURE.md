# Repository Structure

- design-system/: appearance tokens and generated theme CSS
- core/: framework-agnostic shared logic
- apps/main-site/: current live site shell
- apps/editor/: offline editor rebuild target
- apps/collab-rooms/: online collab rebuild target
- apps/plot-studio/: Vite/TS app area
- backend/api/: server routes/functions
- backend/db/: SQL migrations
- archive/: legacy code kept out of live wiring
